# Breast Cancer Detection 🩺

A neural network-based web app that classifies breast tumors as **malignant** or **benign** using cell nuclei measurements from the Wisconsin Breast Cancer dataset. Built with TensorFlow/Keras and deployed as an interactive Streamlit app.

**Live demo:** *(add your Streamlit Cloud link here once deployed)*

## Overview

The model takes 30 numeric features describing the characteristics of a cell nuclei (radius, texture, perimeter, area, smoothness, etc., each reported as a mean, standard error, and "worst" value) and predicts whether the tumor is malignant or benign.

## Tech Stack

- Python
- TensorFlow / Keras
- scikit-learn
- Streamlit

## Dataset

This project uses the **Wisconsin Breast Cancer dataset**, built directly into scikit-learn (`sklearn.datasets.load_breast_cancer`) — no external CSV file is required.

## Project Structure

```
├── app.py                      # Streamlit web app
├── train.py                    # Script to train the model and generate artifacts
├── breast_cancer_model.keras   # Trained neural network (generated by train.py)
├── scaler.pkl                  # Fitted StandardScaler (generated by train.py)
└── requirements.txt            # Python dependencies
```

## Model

A simple feedforward neural network built with Keras:

- Input layer: 30 features
- Hidden layer: 20 neurons, ReLU activation
- Output layer: 2 neurons, sigmoid activation

Trained for 10 epochs using the Adam optimizer and sparse categorical crossentropy loss.

## Running Locally

1. Clone the repository
   ```
   git clone https://github.com/<your-username>/<your-repo>.git
   cd <your-repo>
   ```

2. Install dependencies
   ```
   pip install -r requirements.txt
   ```

3. (First time only) Train the model — this generates `breast_cancer_model.keras` and `scaler.pkl`
   ```
   python train.py
   ```

4. Run the app
   ```
   streamlit run app.py
   ```
